# 감성 일기 생성기 - 웹 버전

카카오톡 대화를 업로드하여 AI가 분석한 감성 일기를 생성하는 웹 애플리케이션입니다.

## 🚀 주요 기능

- **카카오톡 대화 분석**: txt 파일을 업로드하여 대화 내용을 분석
- **감성 일기 생성**: AI가 대화를 분석하여 개인화된 일기를 생성
- **감정 분석**: 일기 내용의 감정 상태를 시각화하여 표시
- **날짜별 분석**: 특정 날짜의 대화만 선택적으로 분석 가능
- **일기 다운로드**: 생성된 일기를 텍스트 파일로 다운로드
- **일기 공유**: 생성된 일기를 클립보드에 복사하거나 공유

## 📋 요구사항

- Python 3.8 이상
- OpenAI API 키

## 🛠️ 설치 및 실행

### 1. 의존성 설치

```bash
pip install -r requirements.txt
```

### 2. 환경 변수 설정

`.env` 파일을 생성하고 OpenAI API 키를 설정하세요:

```
OPENAI_API_KEY=your_openai_api_key_here
```

### 3. 웹 서버 실행

```bash
python run_web.py
```

또는

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 4. 웹 브라우저에서 접속

브라우저에서 `http://localhost:8000`으로 접속하세요.

## 📱 사용법

### 1. 파일 업로드
- 카카오톡 대화를 txt 파일로 내보내기
- 웹 페이지에서 "파일 선택" 버튼을 클릭하여 업로드
- 또는 파일을 드래그 앤 드롭으로 업로드

### 2. 옵션 설정
- **검색 기록**: 오늘 검색한 내용이나 특별한 활동 입력 (선택사항)
- **사용자 정의 프롬프트**: 특별한 스타일이나 요구사항 입력 (선택사항)
- **날짜별 분석**: 특정 날짜의 대화만 분석하려면 체크
- **특정 날짜**: 날짜별 분석 사용 시 원하는 날짜 입력 (예: 6월 14일)

### 3. 일기 생성
- "일기 생성하기" 버튼을 클릭
- AI가 대화를 분석하여 일기를 생성 (약 10-30초 소요)

### 4. 결과 확인
- 생성된 일기 내용 확인
- 감정 분석 차트로 감정 상태 시각화
- 일기 다운로드 또는 공유

## 🔍 API 엔드포인트

### 웹 페이지
- `GET /`: 메인 웹 페이지
- `GET /api/status`: API 서버 상태 확인

### 일기 생성
- `POST /auto-diary`: 파일 업로드 기반 일기 생성
- `POST /generate-diary`: 텍스트 기반 일기 생성

### 테스트 및 분석
- `POST /consistency-test`: 일관성 테스트
- `GET /consistency-test-info`: 일관성 테스트 정보
- `GET /test-date-analysis`: 날짜별 분석 테스트

## 🐛 문제 해결

### 파일 업로드 오류
- 파일이 txt 형식인지 확인
- 파일 크기가 10MB 이하인지 확인
- 파일 인코딩이 UTF-8인지 확인

### 일기 생성 실패
- OpenAI API 키가 올바르게 설정되었는지 확인
- 인터넷 연결 상태 확인
- 파일에 유효한 카카오톡 대화가 포함되어 있는지 확인

### 웹 페이지 로딩 오류
- 서버가 정상적으로 실행되고 있는지 확인
- 브라우저 캐시를 삭제하고 새로고침
- 다른 브라우저로 시도
